# Dashboard interactif de ventes

## Description
Dashboard interactif visualisant les KPIs clés d'un dataset de ventes réel.
Construit avec Python et Plotly pour explorer les tendances et aider à la prise de décision.

## Compétences utilisées
- Python (pandas, plotly)
- Visualisation interactive de données
- Analyse de KPIs métier

## Contenu du dashboard
-  KPIs clés : CA total, meilleur produit, meilleur mois
-  Classement des produits par chiffre d'affaires
-  Évolution mensuelle des ventes
-  Ventes par ville
-  Part du CA — Top 5 produits


## Dataset
Source : [Kaggle - Sales Data Analysis](https://www.kaggle.com/datasets/beekiran/sales-data-analysis)
